## ✨ What is Taxi Tera?

Taxi Tera (ታክሲ ተራ) is a modern navigation platform designed to help people travel across **Addis Ababa** using the city's taxi network.

Instead of memorizing taxi routes, users can explore an interactive map containing **160+ taxi stations** and discover multiple possible paths to their destination.

The goal is simple:

> Make navigating Addis Ababa easier, faster, and less confusing.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Azgames724/Taxi-tera1.2.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Production

```bash
npm run build
```
